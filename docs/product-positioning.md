# 产品定位

dewShot 是一款原生 macOS 截图录屏工具。用户捕获屏幕内容后，可以直接编辑、保存或分享图片和视频。

## 产品主线

- **截图和录屏是核心入口。** 用户需要展示屏幕上的内容时，可以用 dewShot 截一张图或录一段操作。
- **图片和视频编辑是核心体验的一部分。** 截图后可以裁剪、标注或遮挡敏感信息，录屏后可以剪掉多余片段。编辑的目标是让用户直接拿到可以保存或发出去的成品。
- **打开已有文件是编辑能力的延伸。** 目标是让用户从 Finder 选一个本地图片或视频文件，在 dewShot 里编辑并导出。这个场景复用同一套编辑能力，产品介绍仍以截图录屏为主。

## 开发取舍

评估新需求时，先问它能否让用户更顺利地从想截、想录，走到拿到一份能用的图片或视频。捕获的可靠性、捕获后进入编辑的便利性，以及成品能否直接保存或分享，都属于这条主线。

CleanShot X 可以作为同类产品的功能参照。功能重合是可以接受的，优先级由功能对 dewShot 用户完成上述任务的帮助决定。
