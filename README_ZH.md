<h1 align="center">dewShot</h1>

<p align="center">
  一款原生 macOS 截图录屏工具，捕获后可以直接编辑、保存或分享。
</p>

<p align="center">
  <a href="README.md">English</a>
</p>

dewShot 适合那些需要快速展示内容的小场景：反馈问题、解释想法、保存设置、标记界面，或录下一段短操作。按下快捷键，选择你需要的内容，然后复制、保存、编辑、钉住，或稍后再找回来。

所有内容都在你的 Mac 上处理。dewShot 不需要账号，也不会上传截图或录屏。

## 用起来是什么感觉

dewShot 常驻菜单栏，不会打开一个很大的主窗口。每次截图或录屏后，屏幕角落会出现一个小预览。你可以直接复制、保存、编辑、让它保持可见，或者关掉它。
截图或录屏完成后，dewShot 默认也会自动复制到剪贴板，可在「设置 → 捕获」中关闭。
成品复制成功或存入历史后，角落预览默认 30 秒后收起。可在同一设置页调整时长。
菜单会把“截取屏幕”和“录制屏幕”作为两个独立入口，并在操作旁显示已配置的快捷键。
录制屏幕的默认快捷键是 `Command+Shift+R`。
可以在「设置 → 通用」里用 Command、Option 或 Control 加字母或数字自定义快捷键。保存前会检查已知冲突。

目标很简单：拿到你需要的内容，然后继续手头的事。

## 可以做什么

### 截图

- 用 `Command+Shift+A` 选择一块区域。
- 捕获一个窗口。
- 通过滚动捕获较长的内容，在固定侧边预览中查看拼接进度；确认时直接生成已接受的长图，无需重新拼接全部帧。自动滚动会等待每帧结果，停下时显示原因，也可以完成已拼好的部分。
- 支持多显示器。
- 将截图保存为 PNG 文件。

### 从预览继续处理

- 复制截图或录屏。
- 保存到你选择的文件夹。
- 把截图拖到其他应用里。
- 查看更大的预览。
- 钉住图片，让它在工作时保持可见。
- 识别图中文字，并从「全文」或「分块」视图复制。

### 图片编辑

- 打开截图、本地图片，或剪贴板中的图片。
- 在可收起的右侧属性栏调整当前工具或选中对象。
- 在画布上裁剪，按像素或百分比调整尺寸，旋转及翻转。查看图片像素尺寸，并在适合窗口和 100% 之间切换。
- 编辑形状、箭头、文字、高亮和画笔标记，或添加编号、聚光和其他图片。可用马赛克、模糊或纯色遮挡处理局部内容。
- 调整曝光、对比度和饱和度，扩展画布或移除背景。
- 在同一条撤销记录里撤回图片调整和标注。将当前图片和标注保存为本地可编辑工程，方便下次打开继续修改。
- 从编辑器复制成品，或导出 PNG、JPEG、HEIC、TIFF。「保存当前稿」可替换历史图片，也可以保留原图并另存新图。

### 录屏

- 将选定区域录制为 MP4 或 GIF。
- 选择是否显示鼠标、点击和按键。
- 停止、重新开始或删除录屏。
- 裁剪 MP4，并导出更快或更慢的版本。较长的录屏会在时间轴上显示预览帧。

### 找回最近内容

- 双击历史截图直接编辑，或双击录屏开始查看。
- 将历史截图替换为编辑后的版本，或另存一份。
- 把之前的内容放回角落预览里。
- 自己决定最近内容保留多久。

### 外观

- 需要 macOS 26 或更高版本。
- 在「设置 → 通用」里选择「跟随系统」「浅色」或「深色」，截图浮层的 Liquid Glass 会同步切换。截图、录屏和文字识别选项都在「捕获」页。

### 自动启动

- 在设置中开启“登录时启动”，登录 Mac 后即可继续从菜单栏使用 dewShot。

## 权限

dewShot 需要 macOS 的屏幕录制权限（Screen Recording），这样才能在截图或录屏时看到屏幕上的内容。这个名字听起来像只和录屏有关，但截图类应用也需要它。

设置中也会列出辅助功能和输入监控权限。它们分别用于自动滚动和实时按键提示；从系统设置返回 dewShot 后，状态会自动刷新。

更多细节见 [macOS Permissions](docs/permissions.md)。
