description: 为已经在 Mac App Store 发布的 DewShot 版本准备补丁，选择已上架基线、修复问题、送测并在正式上架后回合。
---

先读[发包规范](../../../docs/release.md)。对“继续”先恢复已有候选。正在送审的 major/minor 候选发生返工时，回到原候选分支。

1. **先确认两个问题**：要修什么问题？从哪个已发布版本开始修？列出相关正式版本和 tag，依据影响范围推荐基线，使用用户已经给出的信息。若同一维护线上已有更新 patch，说明旧基线会漏掉哪些后续修复，先确认。历史 GitHub 版本不能充当已上架证明。
2. 从选定版本的正式 tag 创建 patch/X.Y.Z，Z 为下一可用补丁号。复现问题，修复并验证。避免夹带 main 的新功能。
3. 展示相对基线的实际 diff、验证结果、仓库 changelog 和中英文用户说明。等用户确认修复范围后，才分配 build 并按共享 SOP 出包。
4. 未上线的补丁若再返工，产品版本保持 X.Y.Z。Apple 确认该版本正式发布后打 tag、回合 main，并检查正在送审的版本是否也受影响。
